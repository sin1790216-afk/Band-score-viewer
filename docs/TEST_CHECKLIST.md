# 실제 수업 회귀 테스트

## 시작과 동기화

- [ ] Teacher에서 PDF를 열고 해당 JSON을 불러온다.
- [ ] 서버에 이전 페이지가 남아 있어도 Teacher 역할 선택 후 새 Student가 현재 Teacher 페이지로 접속한다.
- [ ] 새 브라우저 또는 새 기기에서 Student로 접속해 현재 PDF, measures, 페이지, 마디에 바로 합류한다.
- [ ] Student에서 나갔다가 역할 선택 화면을 거쳐 다시 진입해도 현재 위치와 하이라이트가 맞는다.
- [ ] Teacher PDF 보기와 학생 개인 PDF 보기 모두 페이지 동기화가 유지된다.
- [ ] Teacher가 수업 종료를 확인하면 접속 중인 Student/Vocal의 PDF, measures와 위치가 초기화된다.
- [ ] 수업 종료 후 새 Student는 이전 악보를 받지 않고 대기 화면을 표시한다.
- [ ] 수업 종료 후 새 PDF를 열면 접속 중인 Student/Vocal이 새 수업 상태를 다시 받는다.
- [ ] 수업 종료가 Student 개인 PDF와 브라우저 로컬 필기를 삭제하지 않는다.

## Student PDF 화면

- [ ] 확대모드에서 하이라이트와 자동 스크롤이 맞는다.
- [ ] 한 페이지 보기에서 페이지 전체와 하이라이트가 맞고 불필요한 자동 스크롤이 없다.
- [ ] 1페이지와 2페이지를 왕복할 때 실제 PDF Page와 하이라이트 페이지가 일치한다.
- [ ] 자동재생 중 페이지 경계를 통과할 때 Student가 즉시 같은 페이지로 전환된다.
- [ ] 세로/가로 화면 회전 후 하이라이트 위치와 크기가 다시 맞는다.

## Student 로컬 필기

- [ ] 필기 모드가 꺼져 있을 때 확대모드의 스크롤과 보기 조작이 기존처럼 동작한다.
- [ ] 빨강, 검정, 파랑을 선택해 그린 선이 각각 선택한 색상으로 유지된다.
- [ ] 필기 중 이전/다음 페이지를 눌러 Teacher와 독립적으로 페이지를 탐색할 수 있다.
- [ ] 필기 중 Teacher가 페이지나 마디를 이동해도 학생의 필기 페이지와 스크롤이 움직이지 않는다.
- [ ] 필기 종료 또는 Esc 후 최신 Teacher 페이지와 마디로 즉시 복귀한다.
- [ ] 확대모드와 한 페이지 보기에서 같은 필기가 PDF의 같은 상대 위치에 표시된다.
- [ ] 페이지를 왕복해도 각 페이지 필기가 섞이지 않는다.
- [ ] 실행 취소는 현재 페이지의 마지막 필기만, 페이지 지우기는 현재 페이지만 제거한다.
- [ ] 새로고침 후 같은 PDF를 다시 열면 이 기기의 필기가 복원된다.
- [ ] Teacher PDF와 학생 개인 PDF의 필기가 서로 분리된다.
- [ ] 학생 필기가 Socket, measure JSON, `.bsv`에 포함되지 않는다.
- [ ] 화면 회전과 전체화면 전환 후 필기 위치가 PDF와 맞는다.

## 모바일 레이아웃

- [ ] 600px 이하 화면에서 Teacher 상단 버튼이 겹치지 않고 PDF 영역이 그 아래에 유지된다.
- [ ] Student의 역할/전체화면 메뉴와 PDF 보기 메뉴가 서로 겹치지 않는다.
- [ ] 세로/가로 회전 후 메뉴가 화면 밖으로 나가거나 PDF 조작을 가리지 않는다.

## 전체화면

- [ ] Teacher, Student, Vocal에서 전체화면 진입과 종료가 동작한다.
- [ ] Student/Vocal 전체화면에서 Esc를 눌러도 역할 선택 화면으로 이동하지 않고 전체화면만 종료된다.
- [ ] 전체화면 전환 후 확대모드와 한 페이지 보기의 PDF·하이라이트 좌표가 다시 맞는다.
- [ ] 전체화면 중 페이지 이동과 자동재생 동기화가 유지된다.

## PWA

- [ ] HTTPS 배포 주소에서 manifest 이름과 192px/512px 아이콘이 인식된다.
- [ ] 설치 후 독립 실행 화면에서 역할 선택과 Teacher/Student/Vocal 진입이 동작한다.
- [ ] 새 버전 배포 후 앱을 다시 열면 이전 화면 코드가 고정되지 않고 최신 버전이 로드된다.
- [ ] PDF와 Socket 상태가 서비스 워커 캐시에 저장되지 않는다.

## Teacher 편집

- [ ] 등록모드에서 마디 생성, 선택, 드래그, 4개 변과 4개 모서리의 8방향 resize, Backspace 삭제가 동작한다.
- [ ] left/top 방향 resize가 반대쪽 경계를 유지하고 페이지 밖이나 최소 크기 아래로 넘어가지 않는다.
- [ ] BPM과 Beats를 수정하고 자동재생 시간이 해당 마디 값에 맞는다.
- [ ] 전체 템포를 적용하면 모든 마디 BPM이 바뀌고, 이후 선택 마디 BPM만 다시 예외값으로 바꿀 수 있다.
- [ ] 전체 템포 적용 후 JSON과 `.bsv`를 왕복해 BPM과 좌표가 유지된다.
- [ ] 여러 줄 lyric을 편집하고 JSON 저장/불러오기 후 그대로 복원된다.
- [ ] ID가 없는 기존 JSON을 불러오면 각 마디에 고유 ID가 생기고, 편집·저장·재불러오기 후 같은 ID가 유지된다.
- [ ] 새 PDF를 열면 이전 measures, 선택, 재생 상태가 남지 않는다.

## 마디 자동인식

- [ ] 순수 barline과 barline 가까이의 분리된 음표는 유지하고, notehead/beam이 직접 붙은 stem은 제외한다.
- [ ] 자동 생성된 같은 system의 Measure가 코드·오선·가사를 포함하는 동일한 세로 content band를 공유한다.
- [ ] 자동인식 후 8방향 resize로 박스를 수동 보정하고 JSON/`.bsv` 재저장 후 좌표가 유지된다.

## 프로젝트 파일

- [ ] PDF, BPM/Beats와 여러 줄 lyric이 있는 프로젝트를 `.bsv`로 저장한다.
- [ ] 음원 링크와 소수점 start offset을 저장한 `.bsv`를 다시 열면 값이 복원된다.
- [ ] `audioSettings`가 없는 이전 `.bsv`를 열면 빈 링크와 0초로 안전하게 보정된다.
- [ ] 새 PDF를 열면 이전 프로젝트의 음원 링크와 start offset이 남지 않는다.
- [ ] `http/https`가 아닌 음원 주소는 링크 열기 버튼으로 실행되지 않는다.
- [ ] Teacher가 음원 링크/start offset을 바꾸면 접속 중인 Student의 선생님 음원 값이 즉시 갱신된다.
- [ ] 늦게 접속한 Student도 서버의 최신 선생님 음원 값을 받는다.
- [ ] Student가 내 음원을 수정해도 Teacher와 다른 Student의 공유값은 변하지 않는다.
- [ ] Student 개인 음원 링크와 start offset은 같은 PDF를 다시 열거나 새로고침한 뒤에도 해당 기기에서 복원된다.
- [ ] 수업 종료는 서버의 선생님 음원 설정을 비우고 Student 개인 음원은 삭제하지 않는다.
- [ ] Student 내 음원에서 MP3/M4A 파일을 선택하면 서버 전송 없이 해당 기기에서 재생된다.
- [ ] Teacher가 공용 로컬 음원을 등록하면 접속 중인 Student와 늦게 접속한 Student 모두 파일명과 음원을 받는다.
- [ ] 공용 음원에서 iPad Safari의 최초 재생, seek, 파형 확대와 0.5x~2x 재생속도가 동작한다.
- [ ] Student가 공용 음원과 내 음원을 왕복해도 개인 File, offset과 마디 타임라인이 유지된다.
- [ ] Teacher가 공용 음원을 교체하면 공용 소스를 사용 중인 Student가 새 revision으로 전환되고 이전 음원이 남아 재생되지 않는다.
- [ ] Teacher가 공용 음원을 제거하거나 수업을 종료하면 Student는 공용 음원 없음 상태가 되고 개인 음원은 유지된다.
- [ ] 공용 음원 `수업 따라가기`에서 Teacher play/pause/seek/재생속도 변경이 Student에 적용된다.
- [ ] 재생 중 늦게 접속하거나 reconnect한 Student가 수업 따라가기를 누르면 Teacher의 계산된 현재 위치에 합류한다.
- [ ] 공용 음원 `개인 연습`에서는 Teacher 명령이 Student 재생 위치를 바꾸지 않고, 다시 수업 따라가기를 누르면 Teacher 위치로 복귀한다.
- [ ] Student 개인 음원은 수업 따라가기 snapshot의 영향을 받지 않는다.
- [ ] iPad Safari에서 최초 수업 따라가기를 직접 눌렀을 때 재생 준비가 되고, 차단 시 안내 후 다시 시도할 수 있다.
- [ ] Teacher 공용 음원 교체 시 playback이 0초·정지·1x로 초기화되고 이전 revision 명령은 무시된다.
- [ ] 음원 설정 패널은 Student 상단의 음원 설정 버튼 바로 아래에 열리고 작은 화면에서도 화면 밖으로 잘리지 않는다.
- [ ] 로컬 음원을 처음 불러오거나 오프셋 이동 버튼을 누르면 duration 범위 안의 start offset으로 이동한다.
- [ ] 로컬 음원의 0.5x~2x 재생속도 선택이 실제 audio playbackRate에 적용된다.
- [ ] 로컬 음원을 재생한 뒤 음원 설정 패널을 닫아도 재생과 현재 위치가 유지된다.
- [ ] 파형을 누르거나 좌우로 드래그하면 재생 위치가 바뀌고, 1x~32x 확대 후에도 미세 조정할 수 있다.
- [ ] iPhone/iPad 파형 위에서 두 손가락을 벌리거나 오므리면 제스처 중심의 음원 위치를 유지하며 확대·축소된다.
- [ ] 현재 파형 위치를 시작점으로 지정하면 저장된 start offset과 노란 기준선이 갱신된다.
- [ ] 음원 설정에서 현재 페이지의 마디 박스를 누르면 대상 마디가 선택되며 Teacher의 syncState는 변하지 않는다.
- [ ] 현재 파형 위치를 대상 마디에 지정하면 marker 시간이 표시되고 박스가 녹색으로 구분된다.
- [ ] 지정된 마디 하이라이트를 누르면 로컬 음원이 해당 위치로 이동한다.
- [ ] 처음 재생, 일시정지 후 재개, 지정 마디 클릭 재생 모두 현재 대상 마디의 BPM/Beats로 한 마디 예비박 후 시작한다.
- [ ] 예비박 첫 박은 높은 음, 나머지 박은 낮은 음으로 들리고 재생속도를 바꾸면 예비박 BPM도 같은 비율로 변한다.
- [ ] 예비박을 OFF로 두면 최초 재생, 재개, 지정 마디 클릭 재생이 즉시 시작된다.
- [ ] 진행 중인 예비박을 OFF로 바꾸면 음원 재생이 즉시 시작되고 음원 설정 패널은 불투명한 열린 상태를 유지한다.
- [ ] 같은 PDF에서 다른 로컬 음원 파일을 선택하면 이전 파일의 마디 marker가 섞이지 않는다.
- [ ] 같은 PDF와 같은 음원 파일을 다시 선택하면 기기에 저장된 마디 marker가 복원된다.
- [ ] 파형에 현재 구간에서 보이는 모든 지정 마디 번호가 표시된다.
- [ ] 음원 따라가기 ON에서 재생·일시정지·파형 탐색 시 현재 시간 이전의 최근 marker 마디로 하이라이트와 페이지가 이동한다.
- [ ] 1마디 위치만 직접 지정해도 이후 마디가 각 마디의 BPM/Beats 누적 시간에 맞춰 이동한다.
- [ ] 중간 마디 위치를 직접 지정하면 그 마디부터 자동 계산 시간이 새 기준점에 맞춰진다.
- [ ] 음원 따라가기 OFF에서는 Teacher의 Socket 페이지/마디를 표시하고 로컬 음원 재생이 Teacher 상태를 변경하지 않는다.
- [ ] `선생님 템포 사용` ON에서는 Teacher의 마디별 BPM 예외까지 사용하고, OFF에서는 저장된 개인 전체·마디별 템포로 즉시 복귀한다.
- [ ] 개인 BPM/Beats는 같은 PDF와 음원 조합에서 복원되며 JSON, `.bsv`, 다른 기기에는 포함되지 않는다.
- [ ] 개인 전체 템포를 적용하면 현재 로컬 timeline의 모든 BPM만 바뀌고 Teacher measure, offset과 직접 marker는 유지된다.
- [ ] Teacher가 1, 2, 3마디를 각각 기준으로 지정하면 기준 마디의 시간이 저장되고 이전 마디는 역산, 이후 마디는 순방향 계산된다.
- [ ] PDF에서 다른 마디를 선택하거나 재생 중이어도 공용 음원 패널에 입력한 기준 마디 번호가 사용된다.
- [ ] 기준 마디 입력은 1부터 전체 마디 수까지만 허용하며 0, 음수, 소수, 초과값과 비숫자 입력에는 오류가 표시된다.
- [ ] 서로 다른 BPM/Beats가 있는 악보에서 각 measure 자신의 duration으로 앞뒤 시작 시간이 계산된다.
- [ ] 역산한 1마디 시작이 음수이면 0으로 보정하지 않고 기준 마디/템포/박자 확인 안내가 표시된다.
- [ ] Teacher가 공용 음원의 선택 마디 기준을 지정하면 접속 중인 Student, 늦게 접속한 Student와 재접속한 Student가 같은 anchor를 받는다.
- [ ] 공용 음원의 `선생님 마디 기준 사용`을 끄면 source별 개인 marker로 복귀하고, 개인 음원에는 Teacher 기준이 자동 적용되지 않는다.
- [ ] 시작 offset을 변경해도 timeline anchor와 계산 marker가 같은 시간만큼 다시 이동하지 않는다.
- [ ] 과거 `firstMeasureAnchorSeconds` 데이터와 legacy Socket event는 1마디 timeline anchor로 읽힌다.
- [ ] Student가 역할을 나가거나 다른 PDF로 전환하면 기존 로컬 음원이 정지하고 다시 선택해야 한다.
- [ ] 모바일 파일 선택 중 페이지가 재생성되면 역할 선택 화면이 아니라 Student 내 음원 패널로 한 번 복귀한다.
- [ ] `.bsv` 저장 전후 모든 measure ID가 동일하고 중복되지 않는다.
- [ ] 다른 PDF를 연 뒤 `.bsv`를 다시 열어 PDF, 파일명, measures와 highlight가 복원된다.
- [ ] `.bsv`를 열면 page 1, measure 0, Stop, Repeat OFF로 초기화된다.
- [ ] 손상되거나 다른 JSON인 `.bsv`를 열었을 때 기존 프로젝트가 그대로 유지되고 오류가 보인다.
- [ ] `.bsv`를 연 뒤 접속 중인 Student/Vocal과 늦게 접속한 화면이 새 PDF/measures를 받는다.
- [ ] 기존 measure 배열 JSON 저장/불러오기가 이전과 동일하게 동작한다.

## 재생과 Vocal

- [ ] 등록모드에서 선택 마디의 Repeat Start/End, Segno, D.S.를 토글하고 Teacher 악보 배지를 확인한다.
- [ ] M3 Repeat Start, M4 Repeat End, M6 Segno, M8 D.S.에서 자동재생 순서가 `1-2-3-4-3-4-5-6-7-8-6-7-8`인지 확인한다.
