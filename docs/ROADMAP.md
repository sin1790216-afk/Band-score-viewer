# 로드맵

아래 순서는 현재 코드 안정화와 실제 수업 우선순위를 반영한 계획이며, 아직 구현 완료를 의미하지 않는다.

1. PDF 렌더 파이프라인 리팩터링: 완료, 실기기 회귀 확인 지속
2. 한 페이지 보기 안정화: 완료, 실기기 회귀 확인 지속
3. stable Measure ID와 프로젝트 `.bsv` v1 저장/불러오기: 구현 완료, Mac/iPad 파일 동작 확인 필요
4. 전체화면/PWA: 전체화면과 설치용 PWA 기반 구현 완료, HTTPS 배포 실기기 확인 필요
5. 연주모드 이동 편의: 마디 번호 이동과 종료 후 처음으로 옵션 구현 완료, 실기기 회귀 확인 지속
6. 학생 PDF 주석: 기기 로컬 펜 필기 MVP 구현, 실기기 검증과 추가 도구는 후속 단계
7. 음원 링크와 start offset: Teacher 공유, Student PDF별 개인 설정과 프로젝트 저장 구현 완료, 실제 재생 연동 제외
8. 개인 연습용 음원-하이라이트 연동과 재생속도: Student 로컬 파일의 지속 재생·파형 핀치 확대·오프셋·재생속도·measure marker·시간 기반 자동 하이라이트·개인 BPM/Beats·한 마디 예비박 구현, 구간 반복은 후속 단계
9. 마디 자동인식 후보 생성
10. 온라인 배포 및 추후 상업화

각 단계는 기존 JSON 호환성과 실제 기기 회귀 테스트를 통과한 뒤 다음 단계로 진행한다.
