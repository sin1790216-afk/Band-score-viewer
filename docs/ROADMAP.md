# 로드맵

아래 순서는 현재 코드 안정화와 실제 수업 우선순위를 반영한 계획이며, 아직 구현 완료를 의미하지 않는다.

1. PDF 렌더 파이프라인 리팩터링
2. 한 페이지 보기 안정화
3. 프로젝트 `.bsv` 저장/불러오기
4. 전체화면/PWA
5. 마디 번호 이동
6. 학생 PDF 주석
7. 음원 링크와 start offset
8. 개인 연습용 음원-하이라이트 연동과 재생속도
9. 마디 자동인식 후보 생성
10. 온라인 배포 및 추후 상업화

각 단계는 기존 JSON 호환성과 실제 기기 회귀 테스트를 통과한 뒤 다음 단계로 진행한다.
